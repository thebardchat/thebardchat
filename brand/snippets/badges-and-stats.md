# Badge & stat-card recipe

All shields.io badges use `style=for-the-badge`, background/label tone `0d1117`, and an
on-palette accent. Reuse these exact accent hexes so badges match across repos.

| Purpose | Accent hex | Example |
|---------|-----------|---------|
| Primary / showcase | `00e5ff` | `![Showcase](https://img.shields.io/badge/SHOWCASE-thebardchat.github.io-00e5ff?style=for-the-badge)` |
| CTA / build | `ffaa00` | `![Built With](https://img.shields.io/badge/Built%20With-Claude%20AI-ffaa00?style=for-the-badge)` |
| Governance / accent | `7c3aed` | `![Constitution](https://img.shields.io/badge/Governed%20by-Constitution-7c3aed?style=for-the-badge)` |
| Twitch | `9146ff` | brand-locked |
| Amazon / book | `ff9900` | brand-locked |
| HuggingFace | `ffd21e` | brand-locked |
