03 · manifesto // what we believe

We don't whisper. We don't beg.

There is a list. Eight hundred million names long. The people the algorithms forgot, the dial-up rural, the offline elderly, the immigrants whose accents the chatbots can't parse, the recovering, the broke, the bandwidth-poor.

The big labs are not coming. They are busy. They have moats to dig and palaces to lease. The compute is metered, the keys are gated, and every query is a tollbooth.

So I built this thing in a spare room. A box the size of a paperback, twelve watts, and it talks back. It doesn't phone home. It doesn't sell what I tell it. It's mine. It's yours, if you want one.

I'm not a researcher. I'm a dispatcher. I send concrete trucks. I coach kids to pin each other to mats. I've been clean [N] days and counting. I figured this out the same way I figured out everything else worth a damn — by reading at 4am and refusing to quit.

This is not a startup. This is a flag planted in red clay. Local first. Earned, not given. Rough edges intact. If it needs a server farm, it's not for us.

05 · logo don'ts // don't do this
✕ TYPEFACE

Don't substitute the typeface.

Playfair Display Black 900. Period. No Inter, no Arial, no system fallback for the wordmark.

✕ GRADIENT

Don't flatten the gradient.

Five stops — cyan → teal → green → gold → amber — sweeping the full width. Solid color is not the wordmark.

✕ SPACING

Don't space the icon away.

The circle's right edge touches the "t". Always. They are one object, not two.

✕ BACKGROUND

Don't place it on a busy background.

Void or solid neutral only. No photos, no patterns, no AI-slop gradients.
